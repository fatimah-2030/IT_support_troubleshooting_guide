Troubleshooting Internet Connection Problems
Problem
A computer cannot connect to the internet.
Possible Causes
• Wi-Fi is turned off.
• The router has a connection problem.
• The computer has an incorrect network configuration.
Troubleshooting Steps
1. Check that Wi-Fi is enabled.
2. Restart the router if authorized.
3. Open Command Prompt (CMD).
4. Run the command ipconfig to check the network configuration.
5. Run ping 8.8.8.8 to test connectivity.
Expected Result
The computer should connect to the internet. If the problem continues, record the error and escalate it to the IT support team.
Project Notes
This guide is for learning and documenting basic IT support troubleshooting.
